# CROSSLINE 发布页

> **使用条款：测试版，仅限授权用户自用，不得转发、反编译、转卖；不开源。**

这里只放 CROSSLINE 编译好的安装包（在右边的 Releases 里），没有源码。

## 安装

1. 打开 [Releases](https://github.com/hui121315/crossline-releases/releases)，下载最新版本的 `crossline-<版本>-linux-x86_64.tar.gz` 和同名的 `.sha256`。
2. 按安装包里的 `INSTALL.md` 做（Ubuntu 22.04 / 24.04，x86_64，2 核 4 GB 起）。

装好以后程序会自己来这里查新版本，**核对发版签名**后才安装；在 设置 → 更新 里可以关掉、换渠道（测试版 / 稳定版）、停在当前版本。

- **测试版**：标着 Pre-release，有新版本就发。
- **稳定版**：测试版稳定运行一段时间后转成正式版本。

发版公钥指纹（`ssh-keygen -lf` 的结果，安装包里的 `release-signers` 是同一把）：`SHA256:Ihhqfndt+hdGSzXes2UM3mThnFiApcZic/iYQLfF10E`

自己用别的网页服务器时，**反向代理到 `127.0.0.1:8000`**（页面和 WASM 都由程序自己提供），不要把安装目录里的 `dist` 挂载出去；实在要挂载，挂整个目录、不挂单个文件。

Source code（zip / tar.gz）是 GitHub 自动附带的，里面只有本说明文件，不含程序源码。

## 升级提示

**从 v2026.10.13-1647 或更早的版本升上来，请按这三步做：**

1. **更新前**，如果交易所 Key 不见了（页面里读不到、`/opt/crossline/prebuilt/.env` 是空的），先用 root 跑下面这条找回。它只在 `.env` 是空的、而更新留下的备份还在时才复制，别的情况什么都不改：

```bash
sudo bash -c 'f=$(find /opt/crossline/prebuilt/.crossline-runtime -path "*update-package/previous/.env" | head -1); if [ -n "$f" ] && [ ! -s /opt/crossline/prebuilt/.env ]; then cp -a "$f" /opt/crossline/prebuilt/.env && systemctl restart crossline-prebuilt && echo 已找回; else echo 没有要找回的; fi'
```

2. **更新后**，用 root 跑 `sudo bash /opt/crossline/prebuilt/scripts/install_signer.sh` 装签名小程序（应用内更新装不了它；它会把 `.env` 里的交易所 Key 导进加密库，问两次口令）。
3. 小程序装好以后，到网页 设置 → 凭证 → 密钥库 输口令解锁。

## 更新记录

### 现在的 CROSSLINE

#### 亮点

- **三个套利控制台**：交易所套利是一张交易台，找机会、建计划、下单、看持仓和自动化都在一页；链上套利、股票套利是自动化控制台，一眼看到机器人在做什么、每个市场的上一次决定、动态和库存。
- **交易台自动化和资金模式**：默认关闭。稳定币模式（默认）只做不需要卖手上币的策略，库存模式全部策略都做；交易所、链上、股票三条线共用每日亏损、每日成交额和每小时笔数上限；只成一腿或结果不明就自己停下并提醒你。
- **对冲转币**：现货跨所时，一边买入，另一边用借币卖、杠杆卖或合约开空先把价差锁住，三种一起算上全部成本，挑最划算的；合约开空这一种可以自动执行（默认关）。
- **自动补币和提币白名单清单**：账户库存低于下限时，可以从余量最多的交易所自动提币补上（默认关，有单笔和每日上限，只提到交易所自己的充值地址）；设置里列出每条路线要加进交易所白名单的地址。
- **成本按交易所官方费率算**：逐家逐币核对费率，读得到账户等级就用实际等级，设置里看得到每个费率的来源；行情只订能配对的币，省流量也更及时。
- **安全加固和备份**：登录用只在服务器保存的会话、错口令过多自动封禁、IP 白名单、网页安全响应头、交易所 Key 体检（能不能提现、有没有绑 IP）；程序用专用用户在只读系统里运行；每日加密备份，一条命令检查服务器安全项。
- **签名发版和自动更新**：每个版本都由发版钥匙签名，服务器核对签名和每个文件后才安装；装在自己服务器上的安装包会自己去发布页查新版本，可以关掉自动安装、选测试版或稳定版、停在当前版本。
- **手机和大屏都顺手**：手机按刘海和底部横条留边，主按钮固定在底部；大屏一屏放下表和详情，界面密度可选。

### 2026.10.14

#### 新增

- **决定日志写出具体原因**：交易台、链上、股票的机器人决定，后端多给一句话时（比如"提交前复检：KRAKEN 现货 USD 可用 12.40，不够这单的 15.00"，或"REST 快照没读到，按 WS 盘口 5 档估"），跟在原因后面用小一号的字写出来，太长截断、鼠标停上去看全文；交易台的"自动化决定"表、机器人列和选中行的"机器人："那行都能看到。没有就不显示。
- **股票套利：美股询价时段也能交给自动化（默认关）**：股票自动化设置里多一个"询价时段"档位，默认是关。
  - 第一档"只出计划"：不发询价，只在决定记录里写本来会向 BP 询价买还是卖、多少股、BP 限价、链上每股价、扣费后净差。同一只股票、同一方向、净差变化不到 0.1% 时不重复记。
  - 第二档"真发"：按时段最小股数向 BP 发询价，收到报价后重新询链上价、建计划。最后一道复检通过才接受报价，同时发出链上交易。复检核这几项：链上报价没过期；BP 账户和钱包余额都是 60 秒内读的；最低利润、每日额度、急停、签名小程序都照旧。
  - 没收到报价、按最低利润挡下、链上报价过期，都写进决定记录，询价让它自己过期，不撤。
  - 只做身份核过、正在实时看价的股票；不能在 BP 和链上之间搬的股票，只用两边现有库存。
  - 开关在股票自动化设置里的"询价时段"（关 / 只出计划 / 真发），另有"允许自动收尾"（默认关）。
- **股票询价成交后的收支看得见了**：接受报价后，交易记录写"已接受报价 · 资金锁定，等 BP 结算"。
  - 成交后按成交记录算两边收支。官方说成交价已含手续费，但没实测过，所以先推一次"需要你"，请你核对费用后手动收尾。设置里另有"允许自动收尾"开关，默认关。
  - BP 结算超时把报价取消、一股没成时，交易所那一腿记 0 收支，链上已成的那一腿走现有的自动补偿：只发一次，有亏损上限。
  - 页面上：这样的记录写"RFQ 已成交，费用待你核对"，排在"需要你"里，股票页顶上也会提醒；按钮写"去收尾"，点进去写着怎么对着 BP 成交记录核费用，核完点"结束并释放预留"。询价看价表里，机器人对某只股票说过的话（比如"只出计划：本来会询价卖 0.01 股……"）跟在那一行后面。

- **设置 → 凭证 → 密钥库 多了"认可路由"**：报价方换了换币合约、签名小程序拒签时，这里醒目列出等你认可的那条：哪条链、完整地址（能复制）、哪家报价方的什么合约、小程序拒签的原话，带区块浏览器和官方出处链接；在官方页核对后输口令认可，链上自动化重新授权后接着跑。名单可以展开看，内置的和你认可过的分开标，每条都能撤销（点两次确认）。链上页顶上的"需要你"会写"路由合约变了"，点"去认可"直接到这一节。服务器支持后出现。
- **急停或签名小程序锁着时，链上、股票的"开自动化"会变灰**：旁边写清楚被什么拦住（"急停中"，或"签名小程序锁着，去 设置 → 凭证 解锁"）；"暂停机器人"照样能点，解锁或关掉急停后自动恢复。
- **链上套利的执行结果，每条腿那一行直接写对账要用的东西**：交易所那一腿写成交均价和订单号，链上那一腿写交易哈希，点一下在区块浏览器里打开，不用再展开"原始反馈"去找。
- **交易台记录把一组现货 + 合约的成本拆开写**：两腿成交、还没平的一组现在在"进行中"，写"持有中"，不再算"已完成"；打开记录能看到开仓成本、平仓成本、已收资金费（几笔）各一行，平仓后再写一句"实际成本 = 开仓 + 平仓 − 已收资金费 = …"。
- **持仓页平仓记录写出净成本怎么算的**：比如"净成本 = 平仓 $0.028 − 已收资金费 $0.0369 = -$0.0089（不含开仓）"，和交易台的"实际成本"（含开仓）对得上口径；持仓行的资金费格多写一句"已收 +$0.0123 · 3 笔"：每组从开仓到现在交易所实际记到账的资金费，鼠标停上去分交易所看、带最后一笔的时间，展开这组时每条腿也各写一行；还没读到的写"已收 —"，不写 0。
- **股票套利记录写实际到账**：链上那一腿有回执后，多一行"实际：链上买到 X 枚 = Y 股"，按回执里的实际数量算，不再只有报价时的"至少买到"。

#### 变更

- **交易所账户模式一改，马上重读**：比如 Gate 从经典账户改成跨币种保证金后，原来按经典方式读余额会一直失败，要等定时重读（最多 10 分钟）才跟上。现在读余额、持仓或挂单时，只要交易所的回复显示"账户模式不对"，就立即重读这家的账户模式（同一家一分钟最多一次）。读到新模式时手上没有仓位，就自动换到新模式的接口；有仓位，照旧先停下等你"按新模式继续"。
- **账户模式每 10 分钟重读一次**：原来每小时才读一次，在交易所把账户升级（比如 Gate 经典账户改成统一账户）后，页面要等将近一小时才显示新模式。现在最多 10 分钟。读失败照旧 2 分钟后重试；手上有仓位时模式变了，照旧先停下等你"按新模式继续"。

#### 修复

- **日志里每 15 分钟多一行内存统计**：开头是"memory report:"，写进程占用的内存、线程数、条数最大的 10 张表以及比上一行涨得最多的 5 张，只写条数不写内容。查内存不用再输口令，看日志这一行就行。

- **"需要你处理"的提醒不能退订了**：通知开着时，机器人停下、成交结果不明、签名小程序锁着、更新验签没过这些要你出手的提醒一定会发，不再看 设置 → 消息通知 里勾没勾；那个框现在勾着、灰掉，旁边写"需要你的提醒总是会发"。通知没开或没配好时，日志里会记一条"需要你：……（webhook 没开，没发出）"，同一条 10 分钟最多记一次，不再悄悄丢掉。
- **更新后不再无故要你重新解锁签名小程序**：发版时签名小程序没改动，就原样沿用上一版的文件，已装好的服务器不会再被换成"新"的、也就不会再被锁上；只有小程序真的有改动那一版，才需要解锁一次。

- **Kraken 现货 + 永续的同所期现能找出来了**：有永续的那些币，Kraken 的 USD 现货报价原来只在有成交时才更新，常常比永续旧好几秒，扫描器要求两边报价时间差在 2 秒内，就当成报价不同步丢掉了。现在这批改成买一卖一一变就推。
- **Hyperliquid 的永续又能和别家配对了**：Hyperliquid 每小时结算一次资金费，但它的接口给的"下一次结算时间"其实是这一小时的开头，程序原样照用，结算时间永远显示已经过去，Hyperliquid 永续从来没和别家配上过对（xyz 那一组干脆没有时间）。现在按"现在之后的下一个整点"算。

- **一家交易所连续鉴权失败时，不再每秒读一次、刷满日志**：签名小程序锁着、或某家 Key 不对时，读这家余额会一直失败。现在连续失败的间隔一次比一次长（30 秒、60 秒、2 分钟、4 分钟，最多 5 分钟），页面刷新也不再为它另起后台读取；同一家同一个原因的警告每分钟只记一条，并写出这一分钟里又失败了多少次。小程序解锁、或 Key 换了以后，立刻恢复正常读取。
- **长时间开着自动化，内存不再只涨不降**：交易台每次找到的对冲机会都会留一份预览和报价单，没人确认的原来永远留着，漏掉的机会行也是。现在没人确认的十分钟后清掉，漏掉的机会行一天后清掉。

- **一批界面小毛病**：
  - 手机上股票记录表不再把整页撑宽 12 像素；
  - 手机上所有折叠标题都按手指大小（44 像素），焦点框统一 2 像素；
  - 出错提示里很长的原始记录会自动换行，不再撑出链上的计划抽屉；
  - 链上设置抽屉里点"应用变更"没保存成功时，提示就写在抽屉里，不再藏在后面的页面上；
  - 链上合约地址旁的"复制 / 清除"按钮变成正常按钮大小；
  - 股票跨所对比搜完整市场名（比如 MUx/USDC）时，不会再把这个市场本身藏掉。

- **交易台平仓后的记录写出平仓那两单**：每条腿下面多"平仓均价"和"平仓单号"（交易所自己的单号），时间线在开仓四步后面接"提交平仓 → 两边平仓成交"，和交易所的成交记录一笔笔对得上。
- **持仓页价格加千分位**：$60000 写成 $60,000，和交易台一样。
- **交易台记录的时间线写日期**：不是今天的步骤写成"10-13 23:58"，持有几天的一组不会看起来像今天早上才做的；今天的照旧只写时分秒。

- **交易台准备下单时，检查列表又看得到了**：1280–1599 宽的屏幕上，计划面板只占上半截，"规则 / 深度 / 风控 / 凭证 / 报价 / 服务端检查"那张列表被挤成 0 高，看不到能不能下单。现在打开计划时面板占整列高度，检查列表至少留三行、不会被挤没；没通过的排最前，再是待检查的，最后是通过的。
- **持仓页小额仓位的数量不再被四舍五入**：0.00025 BTC 原来显示成 0.0003，现在照实写。
- **真钱确认的勾选框好点了**：股票执行、补充余额，以及平仓、全部平仓这些确认框里"确认本次实盘资金操作"一类的勾选框，桌面上原来只有 15 像素高、要瞄准小方块；现在整行文字都能点，高度和其他按钮一样，手机上按手指大小。

### 2026.10.13

#### 新增

- **股票询价看价**：BP 只有询价、没有盘口的股票也进股票市场表了（行上标"询价"）：BP 那边用询价的限价（最坏成交价），和链上池子比，两个方向扣费后的差额写在"两向毛差"那一列；过了提醒门槛写"可做"，现在只看价、不自动下单。报价方暂停、美股时段没开、身份没核过、链上没池子、询价超过 5 秒没更新、BP 关了充提的，整行变灰并写原因，排在后面。表上方写"询价 覆盖 N / 可覆盖 M"，时段没开时写下次开的时间。BP 的 Solana 充值、提现没都开的股票不实时看价，表尾折成一行"充提没开的 N 只"，点开看每只的开关。点开一行看两边的限价、预估价（只做参考）、链上每股价、按多少股算、费用怎么扣、身份依据。服务器支持后出现。

- **持仓接口带"已收资金费"**：每个对冲组在每家交易所已经记到账的资金费合计（USDT，收为正、付为负）、笔数和最后一笔的时间，都来自交易所自己的资金费流水，不是按费率估的；口径和交易台记录一样：只算这一组两条腿的交易所和币对，币种不分大小写；这家还有账单待核对时不出数字。还没读到的就是空，不写 0。页面由前端接上。
- **链上套利：Arbitrum、Base、BNB 链、Optimism 出新区块就读池子**：原来每秒问一次节点有没有新区块；现在这四条链订阅公共节点的新区块推送，一出块马上读池子价格（每条链最多半秒一次，免得被公共节点限流）。推送断了超过 3 秒就自动回到每秒轮询；Robinhood 链没有公共推送，照旧每秒轮询。

- **股票询价看价（后端）**：原来只走询价、没有订单簿的那批股票，现在也能拿 BP 的询价限价和链上池子价比：两个方向都算扣费后的差额，过门槛提醒。只实时看 BP 在 Solana 上充值、提现都开着的股票（现在 74 只），其余折叠成"充提没开的 N 只"；每 5 分钟读一次 BP 的充提开关，开了自动加进来、关了自动停并灰掉，都会发一条通知。每行写明身份依据（BP 列的合约）和能不能搬（可充可提 / 只能充 / 只能提 / 不能充提）。时段没开、BP 不报价、目录里没合约、份额倍率读不到、两边每股价差太多（可能不是同一只）、链上没池子的，这一行会写明原因。页面由前端接上后出现。

#### 变更

- **交易台自动化下单前先核现货的钱**：最后一道复检时，现货买入那条腿要求这家现货账户里计价币的可用余额够"名义金额 + 吃单手续费 + 一点余量"，卖手上的币要求币够卖的数量（借币卖照旧走借币检查）。余额没读到、超过 60 秒没更新，或者这条现货腿的价格 / 数量没读到，都当不够，这笔不下，决定记录里写清"哪家现货、哪个币、可用多少、这单要多少"。原来现货腿不预先核余额，余额不够要等交易所拒单，再按只成一腿回平。
- **安装时默认装上签名小程序，小程序跟着版本自动更新**：新装的服务器会自己建好签名小程序（单独的系统用户、不联网、只写自己的文件夹），之后在网页上设口令、把交易所 Key 存进它的密钥库，不再写进明文 .env；安装包里的小程序和已装的不一样时，由 root 自己的更新单元核对签名后换上，重启后是锁着的，需要你再解锁一次。早就装好的服务器，用 root 跑一次 `sudo bash /opt/crossline/prebuilt/scripts/install_signer.sh` 就能装上，并把 .env 里已有的 Key 收进去（删明文留给你自己决定）。
- **先读出每家交易所的账户模式，再放行自动化**：Gate 的单币种 / 跨币种统一账户、Bitget 的统一账户档位、Bybit 的统一保证金状态、OKX 的账户等级、币安的统一账户（组合保证金）等，上线后先各读一次；读不出来、或者程序还不支持的模式，准备卡"账户模式"标红，这家不进交易台自动化、自动补币、对冲转币、链上交易所腿和股票自动化；模式变了而且有持仓，推一条"需要你"。组合保证金账户一律不开新仓，只减仓的平仓单照发。Gate 统一账户下单、读余额按它自己的规则走；Bitget 杠杆卖只在统一账户高级档能用；币安组合保证金账户的 U 本位合约走专用接口（Key 要开统一账户交易权限），补保证金分两步划。
- **对冲转币按盘口深度算成交价**：自动开一笔对冲转币之前，先把两边的盘口前 10 档按这一笔的数量走一遍，用实际能吃到的均价重算净差；不够门槛、或者 10 档吃不下这个数量，就不开，写明原因。两张开仓单的限价也放到要吃到的最后一档，不会只成第一档、两腿数量对不上。最好的一行按深度不划算时，接着看排第二、第三的行。交易台普通下单本来就按深度算，没变。
- **山寨币不再要求加进地址簿**：OKX、Bybit、Bitget、Kraken 只能提到地址簿里的地址。哪个币在这几家的地址簿里没有，交易台就不从这家转，改从币安、Gate、KuCoin 这类不要求地址簿的交易所出，也不再推"去加地址簿"；稳定币照旧提示加一次 EVM 通用地址。交易所因为地址不在地址簿而拒绝提币时，记成"没发出"，不再当成结果不明、停住自动化。对冲转币里，买入那家要求地址簿、这个币又没加的，详情写"转不出去"。
- **股票套利市场表的"更新"列说实话了**：原来拿的是每轮监控的时间，每次推送都刷新，所以一直是"<1 s"；现在写两边里较旧那一边的数据是多久以前的，比如"链上 12 s"，每秒往上走。Backpack 只在盘口变了才推，所以连着的时候算最新的，断了才按最后一次推送算"BP 40 s"。
- 股票套利一边报价过期时，那一行不再拿旧的毛差当新的显示：数字前面标"旧"，状态改成等两边报价，"预计赚"变成"—"，行的位置照样只在 15 秒一拍时变。
- **会变的数字不再推着页面跳**：年龄、"N s 前"、倒计时、价格、百分比这类每秒都可能变的数，全站用同一种写法：等宽数字放在固定宽度的格子里，右边对齐，格子只会变宽、不会变窄，所以一个数从 9 变到 10 不再把旁边的东西推开；年龄统一写 "<1 s"、"12 s"、"4 min"、"3 h"，过了一分钟就不再每秒跳。交易台、链上、股票的市场表，持仓表，链上设置的诊断（数据来源表整张表不再每次重画），设置 → 诊断 的接口状态和流量表，交易计划的"报价有效"倒计时都换了。
- 链上设置 → 市场里"链 / 报价服务 / 询价来源"那一块和下面"链上对比 · 跨链流程"几行，底色改成和抽屉一样，不再自己一块颜色。
- 1024 宽左右的平板上，链上和股票的"机器人动态"固定高度、在框里滚动，新动态进来不再把下面的库存和记录往下推。
- **没装数据库时，历史有了内存上限**：没有数据库的安装（比如公开版）历史只放在内存里。原来每张表最多 10 万行，实测一行机会记录压缩后约 2.4 KB，攒满要占一两 GB；现在总共最多约 150 MB，满了丢最旧的，页面上的提示会写明"只保留最近约 N 小时"。要长期保留请装数据库。
- 复盘 → 交易：点一行，详情就在那一行下面展开，不再出现在整张表和翻页下面。复盘和交易台的同一笔可以互相跳："在交易台看这笔" / "去复盘看这笔"。
- 自动化参数的"每笔资金"下面写出风控的单笔上限（设置 → 风控），每笔比它大时变黄，提示下单会被拒。
- 结果不明时，计划面板不再给"平掉买入一边 / 平掉卖出一边"按钮（可能平错边）；原来的"人工处理"按钮只是打开日志，改叫"看日志"。
- **转账不再占交易额度**：自动补币和对冲转币的转账只受转账自己的单笔 / 每日上限约束，不再算进交易的每日成交额；交易台状态条单独写"转账 近 24 小时已转 / 每日上限"。
- **真钱测试准备卡更干净**：Hyperliquid 不列提币地址簿；没有维护状态接口的交易所（Bitget、Gate、Hyperliquid）不再列一项"读不到"，改在交易所名字旁边注一句；OKX 的划转权限读不出来，提示改成"到 OKX 网页 API 管理确认勾了「划转」（Transfer）"。
- **OKX 维护状态读得更稳**：OKX 这个接口实际要隔 15–18 秒才能再读（文档写 5 秒），现在被挡后等 20 秒再读一次，首轮随机错开；读不到就保留上次的结果，不再让系统健康变成"降级"。
- **限频按各家文档的规则来**：币安按权重算，用到九成就先停行情查询，下单、撤单和查自己的单照走；被封 IP 时整台主机停到解封，不再接着撞。Bybit、KuCoin 读每次回复里的剩余次数，快用完就先等这个接口。OKX、Bitget 的查余额、充值记录、提币这类钱包接口各走自己的额度，不再挤占下单。
- **杠杆直接卖先看账户设置**：对冲转币里"杠杆直接卖"不再按交易所一律算支持。OKX 要账户是多币种或组合保证金、并开了自动借币；Bybit 要开了现货杠杆、并把 USDT 设成抵押品。每小时读一次账户，缺哪个就写哪个（比如"去 OKX 打开自动借币"），没读到也不算支持。Bitget 的下单自动借币只在拿到的币不能借时才借，卖币换 USDT 能不能借要逐币核对，这个还没接，先不算支持。
- **Kraken 现货私有接口按次数配速**：按 Kraken 官方的调用计数排队发（按最低一档算：最多攒 15 次，每秒回落 0.33 次）；被拒或被限流时，按交易所说的时间等，不再接着撞。
- **下第一条腿前，两条腿都先对一遍交易所的单笔上限和价格带**：数量、金额超过交易所规定的单笔上限，或者价格超出它允许的范围，就两条都不下，并写清楚是哪条腿、哪一条规则。交易所没公布的、或者按系统读不到的参考价算的，写"未预检"，自动化的决定记录里也会带上这一句。
- **Hyperliquid 永续开仓至少 $12**：Hyperliquid 每单最少 $10，没写平仓单是否例外。所以开仓按 $10 × 1.2 起步，平仓一次平完。
- **KuCoin 合约账户是双向持仓、Gate 合约账户是分仓模式时，开仓前就不做**：写明"先改成单向"之类的原因，不再等到平仓才失败。
- **币安合约资金费间隔每小时核一次**：建计划时，币安没在表里列出的交易对，按最近两次结算的时间差核一次；核出来和行情里的不一样就先不建，核不到就按 8 小时算并写"推断"。

#### 修复

- **交易台自动化的库存下限按每条腿自己的计价币算**：原来除 Hyperliquid 外一律按 USDT 算，Kraken 的 USD 现货和 USD 永续会被显示成"不够"、建议去补 USDT。现在现货买入按这一对自己的计价币看（Kraken 的 USD 对看 USD、USDT 对看 USDT），读不出计价币时才按这家交易所的默认；Kraken 永续的保证金按 USD 看。

- **Kraken 同所期现能凑出来了**：Kraken 永续是 USD 计价，但扫描用的 Kraken 现货盘口原来只有 USDT / USDC 的，凑不出"现货买 + 永续空"。现在把 Kraken 上有永续的那些币的 USD 现货盘口也订进来（只订这些，不订全部 USD 现货），同一家、不用转账、不用换汇。服务器日志每 5 分钟按交易所记一行：进了扫描的永续、门槛前的候选、过门槛的行数。

- **股票询价看价重启后不再一律显示"时段未开"**：交易日历原来只在页面选中一只股票时才读，服务器重启后没人选，询价看价全部灰成"官方交易日历还没读到"。现在询价看价每 5 分钟自己读一次日历；日历还没读到时，按 BP 询价推送自带的时段和价格判断，推送有价就照常算差额。

- **交易台自动化的当日盈亏按实际手续费算**：原来复盘只认交易所用 USDT / USDC / USD 报的手续费，有一张单的手续费是币（比如币安现货买入扣币）或者没报，这笔交易的净额就算"没核完"，当天自动化会停下不开新单。现在每张单的手续费从交易所的成交推送读：USD 稳定币原样算，是币的按成交价折算，没报的按这家的吃单费率估；当日净额照常出来，暂停原因里写明"今日净额里 N 张单的手续费按吃单费率估"。对冲转币那一轮的盈亏也用同一套。
- **对冲转币的回款扣掉手续费了**：连利润一起回款时，原来按 B 上平仓所得全额回，没扣 B 上几张单的手续费，回的比 B 这一轮实际多出来的钱略多。现在每张单成交后读交易所报回的手续费（币安、OKX、Bybit、Kraken 现货、KuCoin 现货的成交推送会带币种）；手续费是币的按成交价折成 USDT；交易所没报的，按这家的吃单费率保守扣，并在事件里写明是估的。只回本金的计划回 A 实际买入花的，但不超过 B 这一轮扣掉手续费后实际得到的：这一轮亏了，就按 B 实际所得回，事件里写"这一轮亏了 X（手续费 Y、平仓滑点 Z）"，不拿 B 原有的钱补差额。

- **签名小程序锁着时，每个页面顶上都写出来**：服务器重启后小程序锁着，交易台、链上、股票的自动化都停住；以前只有交易台自动化那一行写了原因，现在顶上状态行变成红色"签名小程序锁着"，写明去 设置 → 凭证 → 密钥库 输口令解锁，解锁后自己消失。
- 股票套利的记录里多一行"股数换算"：链上买到（或卖出）多少枚代币 × 份额倍率 = 多少股，旁边写交易所下单的股数（按交易所最小单位向下取整），方便和两边的成交记录对账。
- 链上"手动建计划"抽屉里，执行结果的每条腿进度（下单 → 成交 / 到账 → 确认 → 对账）不再挤成一团：地方窄时改成上下排。
- 从交易台"去复盘看这笔"跳过去、这一笔还没进复盘时，写"这一笔还没进复盘：两边成交、费用核齐后才会出现"，不再写"最近 30 天没有已完成的交易"。
- 股票套利页顶上"交易需处理"这类资金提示是个按钮，不再横跨整页像一条空白的条。

- **Kraken 合约故障恢复时不再接连丢数据**：Kraken 合约断线重连后，所有行情和盘口会一起重新推过来，原来的接收队列太小，一秒内丢了 42 次、每次都清缓存重订盘口。队列放大到和币安永续一样，重连那一下装得下。
- **Kraken 永续进扫描了**：原来 Kraken 永续的计价币被当成"不知道"，扫描器从来不看它（1 小时、24 小时里 Kraken 永续的候选都是 0）。按 Kraken 官方文档，永续全是 USD 计价，现在照这个认：Kraken 现货（USD）加 Kraken 永续（USD）的同所期现可以执行；和别家 USDT 永续配对属于跨计价币，照现有规则只显示、不执行。
- **股票自动化的每日额度和净盈亏不再漏算**：原来只看页面上那 48 条记录，忙的时候自己的单被挤出去就少算了；现在从全部记录里算。按订单编号找计划、查编号冲突也在全部记录里找。
- **链上自动化不会因为执行记录太多而误停**：原来一天超过 128 笔执行时，自己的单被挤出去，会以为"近 24 小时结果还没核对完"而停新单；现在按自己的单逐个查，查到的净额会记下来。
- **自动化停住后，页面直接给出重新授权的地方**：出事停住后要重新授权才能继续，原来页面以为授权还有效，把授权的地方藏起来了。
- **自动化状态读不到时，不再显示"自动化中"**：链上和股票页上，读取失败时写"状态待确认，上次在运行"。
- **现货跨所、现货永续不再被"指数成分"拦**：指数成分是永续合约的东西，和现货无关，现在只挂在两边都是永续的行上；加密货币永续的成分也只做提示、不再拦（KuCoin 这类不公布成分的交易所不会被一直拦住）。股票、指数、金属这类永续的规则不变。现在能不能下单，不再取决于有没有人点开过详情。
- **认币看交易所币种列表里的合约地址**：两边在同一条链上是同一个合约，或者都是这条链的原生币（比如 LUNC），就算同一个币；合约不同就拦"同名不同币"；什么都对不上时只提示，手动下单前请自己核对，自动化不做这一行。某家交易所的币种清单还没读到时也一样：自动化先不做，交易台的决定记录写"资料没核对"；像 Hyperliquid 这种本来就不公布合约地址的交易所，只按两边价格尺度核，提示一句，自动化照常做。
- **指数成分重合度算对了**：交易所对同一个市场的写法不一样（ONEUSDT 和 ONE/USDT、Mxc 和 MEXC），原来对不上，算出 0、页面还显示成"-0%"；现在 ONE 在币安和 Bitget 之间的重合度算出约 39%。
- **服务器内存一直涨的最大一块收住了**：资金费差的统计原来每对每分钟存一整行、留三天，7800 多对攒下来很大。现在每对每 5 分钟只存一个很小的样本（平均值和波动），按满三天算也不超过 50 MB，而且不再涨；资金费页 1 / 3 / 9 周期的数字和原来基本一致。写进历史库的资金费差也改成每对每 5 分钟一行，少了约八成。另外没装数据库时内存里的机会记录占得更紧，推送给页面的积压有了上限（落后太多就重读一次快照），监控页 /metrics 多了几张表的条数和字节数，方便以后查内存。重启后从历史库读回的行也按完整样本算，指标页里统计的行数 / 字节数不再被历史查询临时建的统计覆盖成小数；订单、成交这类逐条事件落后时不丢积压（只有整张快照的机会、资金费会丢旧的）。
- **一家交易所读余额出事，不再拖住别家**：重启时碰上某家（比如 Kraken）正在故障，它的余额读不到、进入冷却，原来整批余额读取会因为它直接作废：页面和账户状态里余额一行都没有，别家的余额缓存过期了也没人补读。现在每家各读各的：读得到的照常刷新、照常显示，读不到的只是那一家空着、标"未知"，冷启动最多等 8 秒收第一批答案。
- **对冲转币平仓只补没平的那一部分**：平仓单或回平单只成交了一部分时，下一次只发剩下的，不再因为"成交过"就当成平完了；回款按买入实际花的钱、卖出实际收回的钱算，不再按计划额；同一轮的转账被再次提交，只会拿回原来那一笔，不会多提一次（重启后同样）；平仓时有一个价格读不到，不会再把没发出去的单记成"已发送"。页面上对冲转币的敞口行，把每一次平仓、回平、买入、还款都算进去，成交量还没核到的写"剩余仓位待核对"，不再当成 0。
- **对冲转币：结果不明的平仓单和迟到的币能接上了**：平仓单结果不明时，系统隔 1 分钟再按客户端编号查，查 3 次；还查不到就推"需要你"，之后每 5 分钟再查一次，你到交易所核对后也能直接报结果。提币超时被停住后币才到的，在"结果不明"里点"继续"：系统重新读到账、B 那边的币和对冲，三边对得上才接着平仓，对不上不动。
- **交易台自动化：第一张单发出前再核一次**：慢检查都做完、第一张单马上发出的那一刻，再确认一次自动化还开着、没暂停、参数没改、没有拦截；点暂停赶在这之前，这一笔就不发，之后才点暂停，只停下一笔。提交前用刷新后的盘口重算"最低净收益"和"最低深度"，不达标就不发，写明"提交前复检：净收益 X bps 低于门槛 Y"或"深度不够"。每日亏损和"结果还没核完"现在对所有自动开仓（包括对冲转币）一视同仁：已经亏到当日上限、或者有一笔结果还不知道，就不再开新的。对冲转币的已结算盈亏（自己的成交减手续费和本金的转账费）也算进每日盈亏。开仓次数按开仓时间算、盈亏按平仓时间算，持仓很久的不会被漏掉；被"同市场已有仓 / 估值 / 上下文"拦下、没发出单的，不再占用次数和成交额。状态条写明"已开启，当前被急停拦住""实盘开关没开"或被哪条每日上限拦住，读不到写"状态待确认"，不再一律写"运行中"。
- **对冲转币算对了合约名里的倍数**：币安、Bybit、Bitget、KuCoin 有些永续叫 `1000LUNC`、`1000BONK`，一张或一个单位是 1000 个币，价格也是 1000 个币的价格。以前直接拿来和现货比，会显示"合约和现货差价太大（99733%）"。现在价格按每个币换算；开空的数量、平仓的价格、对冲敞口的美元数也一起换算。交易台本来就按同名合约配对，不受影响。
- **签名小程序装好后，Kraken 的私有通道一直起不来**：小程序把主程序认账户用的"账户指纹"也拒签了，Kraken 就没有账户，私有通道一开头就结束。现在小程序允许 Kraken 的密钥签这一种（别的照旧不签）；需要在服务器上换一次小程序，再输一次口令。Kraken 私有通道结束时，日志里也会写清是哪一路、为什么。
- 设置 → 日志 的操作记录：打开"技术详情"后再搜索，详情不再自己收起。
- 设置 → 诊断 → 接口状态 的运行状态表：可以用键盘选中一行，按回车或空格展开完整记录。
- 设置 → 行情：读取失败显示上次数据时，"上次有延迟 · 7 条 · 本地缓存 · 刚刚"这类字窄屏下会换行，不再被截掉。
- 手机上的设置页：底部有"保存"按钮条时，用键盘或跳转定位到的内容不会被按钮条挡住。
- 股票套利 库存：Solana 钱包里的 SOL 显示在"SOL Gas"一栏，不再被算进"股票"那栏。
- 交易台"结果不明"不再说成"另一边没成"：一腿成交、另一腿的结果不知道时（比如下单回复丢了），写"X 那笔结果不明：先到 X 查订单 … 有没有成交，再决定平哪边"，阶段写"结果不明"，免得照着去平掉另一边反而留下单边仓位。
- 交易台"需要你处理"把结果不明的转账、停住的对冲转币也列进去，点"去处理"直接到自动化决定。
- 交易台成交记录对得上交易所：每腿写成交均价、手续费、交易所的订单号；没对账时实际成本写两腿手续费合计（注明只含手续费）。复盘里每腿的成交后面也写手续费和单号。
- 交易台转账和对冲转币各加一行进度（提币 → 链上 → 到账 → 进交易账户；同时开仓 → 转币 → 平仓 → 回款），对冲转币还写买入和对冲的数量差（敞口）。
- 交易台状态条加"今日 已用 / 每日上限"，改完额度马上能看到。
- 手机上交易计划面板的步骤不再压在"技术详情"下面。
- **自动补币到账正好是要的数**：原来一律当"手续费从提币数量里扣"算，但余额又按"数量 + 手续费"核，两头对不上：手续费从数量里扣的交易所到账少一笔手续费。现在按每家的口径算：OKX、Bybit、Kraken 的手续费另外收，就提要的数；KuCoin、Bitget、币安、Gate 从数量里扣，就提"要的数 + 手续费"。
- OKX 提币被要求填收款人信息（旅行规则），或身份认证不够时，按"没发出 + 需要你"处理并写清原因，不再算结果不明。
- Kraken 合约的订单按编号读回时，不再把挂在簿上的单、已经成交的单都读成"被拒"：交易所返回的状态词（在簿上、全部成交、已取消、触发单已挂等）现在都按文档映射，认不出的词会停下等人，不再当成被拒。
- 币安订单读回认得文档里的两个状态词：`PENDING_NEW` 当等待（还没进簿），`EXPIRED_IN_MATCH`（自成交保护把单子过期了）当终态并带上已成交数量，以前这两个词会让这一单停在“需要你”。
- **程序只读安装目录里的 .env**：原来会从启动目录一级级往上找 .env，测试时挂了生产目录就读到了生产的明文 Key。现在只读两处：环境变量 `CROSSLINE_ENV_FILE` 指定的文件，或者安装目录里的 .env。设置页保存的凭证也写进同一个文件。启动日志里写着读了哪个文件（只写路径）。
- KuCoin 现货规格刷新修复：KuCoin 有 16 个法币计价的交易对（如 BTC-EUR）的最小下单金额字段是空值，批 50 起这一个空值会让整张 KuCoin 现货规格表读不进来（日志里每分钟一条“instrument refresh failed”）；现在这些交易对照常读，最小金额回退到 quoteMinSize。

#### 修复

- **公开测试版更新后，自己挂载的目录不再指向旧版本**：以前自动更新会把整个 `dist`、`deploy` 等文件夹换成新的，用 Docker 把 `dist` 挂载出去的网页服务器还停在旧文件夹里，新版页面 404。现在更新只替换文件，文件夹原地不动，挂载的容器不用重启就读到新文件，退回也一样；程序自带的 Caddy 在更新后会自动检查容器看到的是不是当前的 Caddyfile，不是就重新启动它。装这一版的那次更新还是旧程序在换文件，装完请重启一次挂载 `dist` 的容器；从这一版往后的更新就不用了。自己配网页服务器时，建议直接反向代理到 `127.0.0.1:8000`，不要挂载 `dist`（安装说明里写了）。
