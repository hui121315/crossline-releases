# CROSSLINE 发布页

> **使用条款：测试版，仅限授权用户自用，不得转发、反编译、转卖；不开源。**

这里只放 CROSSLINE 编译好的安装包（在右边的 Releases 里），没有源码。

## 安装

1. 打开 [Releases](https://github.com/hui121315/crossline-releases/releases)，下载最新版本的 `crossline-<版本>-linux-x86_64.tar.gz` 和同名的 `.sha256`。
2. 按安装包里的 `INSTALL.md` 做（Ubuntu 22.04 / 24.04，x86_64，2 核 4 GB 起）。

装好以后程序会自己来这里查新版本，**核对发版签名**后才安装；在 设置 → 更新 里可以关掉、换渠道（测试版 / 稳定版）、停在当前版本。

- **测试版**：标着 Pre-release，有新版本就发。
- **稳定版**：测试版稳定运行一段时间后转成正式版本。

发版公钥指纹（`ssh-keygen -lf` 的结果，安装包里的 `release-signers` 是同一把）：`SHA256:Ihhqfndt+hdGSzXes2UM3mThnFiApcZic/iYQLfF10E`

自己用别的网页服务器时，**反向代理到 `127.0.0.1:8000`**（页面和 WASM 都由程序自己提供），不要把安装目录里的 `dist` 挂载出去；实在要挂载，挂整个目录、不挂单个文件。

Source code（zip / tar.gz）是 GitHub 自动附带的，里面只有本说明文件，不含程序源码。

## 更新记录

### 现在的 CROSSLINE

#### 亮点

- **三个套利控制台**：交易所套利是一张交易台，找机会、建计划、下单、看持仓和自动化都在一页；链上套利、股票套利是自动化控制台，一眼看到机器人在做什么、每个市场的上一次决定、动态和库存。
- **交易台自动化和资金模式**：默认关闭。稳定币模式（默认）只做不需要卖手上币的策略，库存模式全部策略都做；交易所、链上、股票三条线共用每日亏损、每日成交额和每小时笔数上限；只成一腿或结果不明就自己停下并提醒你。
- **对冲转币**：现货跨所时，一边买入，另一边用借币卖、杠杆卖或合约开空先把价差锁住，三种一起算上全部成本，挑最划算的；合约开空这一种可以自动执行（默认关）。
- **自动补币和提币白名单清单**：账户库存低于下限时，可以从余量最多的交易所自动提币补上（默认关，有单笔和每日上限，只提到交易所自己的充值地址）；设置里列出每条路线要加进交易所白名单的地址。
- **成本按交易所官方费率算**：逐家逐币核对费率，读得到账户等级就用实际等级，设置里看得到每个费率的来源；行情只订能配对的币，省流量也更及时。
- **安全加固和备份**：登录用只在服务器保存的会话、错口令过多自动封禁、IP 白名单、网页安全响应头、交易所 Key 体检（能不能提现、有没有绑 IP）；程序用专用用户在只读系统里运行；每日加密备份，一条命令检查服务器安全项。
- **签名发版和自动更新**：每个版本都由发版钥匙签名，服务器核对签名和每个文件后才安装；装在自己服务器上的安装包会自己去发布页查新版本，可以关掉自动安装、选测试版或稳定版、停在当前版本。
- **手机和大屏都顺手**：手机按刘海和底部横条留边，主按钮固定在底部；大屏一屏放下表和详情，界面密度可选。

### 2026.10.13

#### 新增

- **一条腿结果不明时，页面上能收尾了**：系统先按客户端编号自己去交易所查（隔 1 分钟，查 3 次），查到就照原来的规则往下走。还是查不到，就推一条"需要你"，写清哪一家、哪个币、多少、客户端编号。你去交易所核对后，在页面上选"成交了 X / 没成交 / 我自己处理"，每次都要再确认一次。系统据此算出多出来多少，给出"平掉多出来那一腿"的方案，写清下哪张单、多少、什么价、预计手续费；你确认后才发，只发一次。行情变了 2% 以上，或者收尾单只成交一部分、没成交，页面写清还剩多少没平，可以一键按现价重新出方案（还是要你确认）。选"我自己处理"后，系统不再动这一轮，自动化保持停住，等你自己打开。你报的数和交易所后来查到的对不上时，以交易所为准，再叫你核。每一步都记进审计日志。交易台的两条腿、对冲转币的各段订单（包括杠杆卖）都适用。
- **交易台自动化可以限定交易所**：自动化规则里多了"交易所范围"，只在选中的几家里做（两条腿都要在里面）；没选就和现在一样不限。其他交易所的机会在决定记录里写"不在自动化交易所范围"。
- **对冲转币显示敞口金额**：还开着的对冲按 B 的中间价折成美元，写明价格来源和时间。

- **结果不明的那一腿，在页面上收尾**：一腿成交、另一腿查了几次还是不知道结果时，交易计划面板多一块"收尾这笔"：写清哪家、哪个币、多少、客户端编号和交易所单号。你到交易所查完后选"成交了（填数量，均价可不填）/ 没成交 / 我自己处理"，再确认一次才报上去；系统据此给出收尾方案（下哪张单、多少、最差价、预计成本），你再确认一次才发，只发一次。选"我自己处理"后系统不再动这一轮，交易台自动化保持停住。服务器支持后出现。
- **交易台自动化可以限定交易所**：改参数里多一行"交易所范围"，点选几家，只在选中的几家里做（两条腿都要在里面）；都不选就和现在一样不限。状态条写"只做 okx · bitget"，其他交易所的机会在决定记录里写"不在自动化交易所范围"。设置 → 风控 的"允许交易所"照样管所有下单。
- **对冲转币显示敞口金额**：还开着的对冲按 B 的中间价折成美元，写明价格来源和时间。

- **对冲转币的"杠杆直接卖"多了 Bitget、Gate、KuCoin**：和币安、Bybit、OKX 一样，开仓前查能借多少和账户设置，平仓买够差额、一次还清，读一遍欠款是 0 才算平仓；跑的过程中盯着离强平还有多远。平仓买差额改成普通现货单，USDT 不够时不会悄悄借 USDT。
- **对冲转币能用"杠杆直接卖"了（币安、Bybit、OKX）**：在 B 上下一个卖单，下单时自动借币卖出，和合约开空一起比价，谁划算用谁；默认关，要开"允许对冲转币"和实盘开关。开仓前先查杠杆账户设置、抵押品和能借多少，缺什么写清楚；币到了以后先买够利息和手续费的差额，再一次还清，读一遍欠款是 0 才算平仓，不是 0 就停下来叫你。跑的过程中盯着杠杆账户离强平还有多远，太近就提前买回还掉，再叫你。对冲转币的成交额和笔数也算进交易台的每日上限。
- **内存一直涨时能查出是哪张表**：监控页面 /metrics 多了两组只读数字——每张长期保存的表现在有多少条，和系统看到的进程内存（总量、堆、文件、交换）。长时间运行内存不停上涨时，对着这两组数字就能看出是哪张表在涨。
- **真钱测试准备**：设置 → 凭证 最上面多了一张卡，把真钱测试前要在交易所改好的设置放在一起：每家交易所的提币和内部划转权限、Key 有没有绑 IP、提币地址簿、合约持仓模式、现货杠杆、是否维护中，以及签名小程序。第一行写还有几项要处理，下面按交易所列出，问题最多的排前面，每项写现在是什么、怎么改。只显示，不会替你改任何交易所设置；手机上没问题的交易所默认收起。内容来自 Key 体检、白名单清单上次读的结果、KuCoin 和 Gate 的合约持仓模式、OKX 和 Bybit 的杠杆设置、维护状态；一分钟内重复打开不会再去问交易所。
- **Kraken 合约挂单保护看得见了**：Kraken 一部分合约市场，不是只挂单的单子要先等 20 毫秒（最多 100 毫秒）才撮合，中途撤单也拦不住。现在读每个市场的等待时间：设置 → 诊断 → 交易 的 Kraken 永续一行写着有多少个市场、要等多久；有 Kraken 合约腿的机会（包括对冲转币选了合约开空）会多一条时间风险提示；下单后等成交确认的时间也加上这一段。
- **OKX、KuCoin 到账后也能划到交易账户**：充值地址进的是资金账户时，到账后只把这一笔划到交易账户。OKX 划完要再查一次结果才算数。KuCoin 选充值地址时，优先选直接进交易账户的那个。这两家还没开放成自动补币的目的地。
- **OKX、Gate、KuCoin 也能自动提币了**：和币安、Bybit、Bitget、Kraken 用同一套规矩：先记下再发，只发一次；结果不明就暂停并提醒你，不重发；实盘开关只有你能开。发之前先按交易所自己的规则逐条核对：能不能提、单笔最少和最多、今天还剩多少额度、小数位、手续费不能超过批准的数、要不要填标签、账户里的钱够不够。哪条不过就不发，并写清是哪一条。OKX 和 KuCoin 只能从资金账户提，钱在交易账户的会提示先划过去。这三家还没开放成自动补币的来源。

#### 变更

- **没装数据库时，历史有了内存上限**：没有数据库的安装（比如公开版）历史只放在内存里。原来每张表最多 10 万行，实测一行机会记录压缩后约 2.4 KB，攒满要占一两 GB；现在总共最多约 150 MB，满了丢最旧的，页面上的提示会写明"只保留最近约 N 小时"。要长期保留请装数据库。

- **转账不再占交易额度**：自动补币和对冲转币的转账只受转账自己的单笔 / 每日上限约束，不再算进交易的每日成交额；状态里单独显示近 24 小时转了多少。

- 复盘 → 交易：点一行，详情就在那一行下面展开，不再出现在整张表和翻页下面。复盘和交易台的同一笔可以互相跳："在交易台看这笔" / "去复盘看这笔"。
- 自动化参数的"每笔资金"下面写出风控的单笔上限（设置 → 风控），每笔比它大时变黄，提示下单会被拒。
- 结果不明时，计划面板不再给"平掉买入一边 / 平掉卖出一边"按钮（可能平错边）；原来的"人工处理"按钮只是打开日志，改叫"看日志"。
- **转账不再占交易额度**：自动补币和对冲转币的转账只受转账自己的单笔 / 每日上限约束，不再算进交易的每日成交额；交易台状态条单独写"转账 近 24 小时已转 / 每日上限"。
- **真钱测试准备卡更干净**：Hyperliquid 不列提币地址簿；没有维护状态接口的交易所（Bitget、Gate、Hyperliquid）不再列一项"读不到"，改在交易所名字旁边注一句；OKX 的划转权限读不出来，提示改成"到 OKX 网页 API 管理确认勾了「划转」（Transfer）"。
- **OKX 维护状态读得更稳**：OKX 这个接口实际要隔 15–18 秒才能再读（文档写 5 秒），现在被挡后等 20 秒再读一次，首轮随机错开；读不到就保留上次的结果，不再让系统健康变成"降级"。
- **限频按各家文档的规则来**：币安按权重算，用到九成就先停行情查询，下单、撤单和查自己的单照走；被封 IP 时整台主机停到解封，不再接着撞。Bybit、KuCoin 读每次回复里的剩余次数，快用完就先等这个接口。OKX、Bitget 的查余额、充值记录、提币这类钱包接口各走自己的额度，不再挤占下单。
- **杠杆直接卖先看账户设置**：对冲转币里"杠杆直接卖"不再按交易所一律算支持。OKX 要账户是多币种或组合保证金、并开了自动借币；Bybit 要开了现货杠杆、并把 USDT 设成抵押品。每小时读一次账户，缺哪个就写哪个（比如"去 OKX 打开自动借币"），没读到也不算支持。Bitget 的下单自动借币只在拿到的币不能借时才借，卖币换 USDT 能不能借要逐币核对，这个还没接，先不算支持。
- **Kraken 现货私有接口按次数配速**：按 Kraken 官方的调用计数排队发（按最低一档算：最多攒 15 次，每秒回落 0.33 次）；被拒或被限流时，按交易所说的时间等，不再接着撞。
- **下第一条腿前，两条腿都先对一遍交易所的单笔上限和价格带**：数量、金额超过交易所规定的单笔上限，或者价格超出它允许的范围，就两条都不下，并写清楚是哪条腿、哪一条规则。交易所没公布的、或者按系统读不到的参考价算的，写"未预检"，自动化的决定记录里也会带上这一句。
- **Hyperliquid 永续开仓至少 $12**：Hyperliquid 每单最少 $10，没写平仓单是否例外。所以开仓按 $10 × 1.2 起步，平仓一次平完。
- **KuCoin 合约账户是双向持仓、Gate 合约账户是分仓模式时，开仓前就不做**：写明"先改成单向"之类的原因，不再等到平仓才失败。
- **币安合约资金费间隔每小时核一次**：建计划时，币安没在表里列出的交易对，按最近两次结算的时间差核一次；核出来和行情里的不一样就先不建，核不到就按 8 小时算并写"推断"。

#### 修复

- **对冲转币算对了合约名里的倍数**：币安、Bybit、Bitget、KuCoin 有些永续叫 `1000LUNC`、`1000BONK`，一张或一个单位是 1000 个币，价格也是 1000 个币的价格。以前直接拿来和现货比，会显示"合约和现货差价太大（99733%）"。现在价格按每个币换算；开空的数量、平仓的价格、对冲敞口的美元数也一起换算。交易台本来就按同名合约配对，不受影响。

- **签名小程序装好后，Kraken 的私有通道一直起不来**：小程序把主程序认账户用的"账户指纹"也拒签了，Kraken 就没有账户，私有通道一开头就结束。现在小程序允许 Kraken 的密钥签这一种（别的照旧不签）；需要在服务器上换一次小程序，再输一次口令。Kraken 私有通道结束时，日志里也会写清是哪一路、为什么。
- 设置 → 日志 的操作记录：打开"技术详情"后再搜索，详情不再自己收起。
- 设置 → 诊断 → 接口状态 的运行状态表：可以用键盘选中一行，按回车或空格展开完整记录。
- 设置 → 行情：读取失败显示上次数据时，"上次有延迟 · 7 条 · 本地缓存 · 刚刚"这类字窄屏下会换行，不再被截掉。
- 手机上的设置页：底部有"保存"按钮条时，用键盘或跳转定位到的内容不会被按钮条挡住。
- 股票套利 库存：Solana 钱包里的 SOL 显示在"SOL Gas"一栏，不再被算进"股票"那栏。
- 交易台"结果不明"不再说成"另一边没成"：一腿成交、另一腿的结果不知道时（比如下单回复丢了），写"X 那笔结果不明：先到 X 查订单 … 有没有成交，再决定平哪边"，阶段写"结果不明"，免得照着去平掉另一边反而留下单边仓位。
- 交易台"需要你处理"把结果不明的转账、停住的对冲转币也列进去，点"去处理"直接到自动化决定。
- 交易台成交记录对得上交易所：每腿写成交均价、手续费、交易所的订单号；没对账时实际成本写两腿手续费合计（注明只含手续费）。复盘里每腿的成交后面也写手续费和单号。
- 交易台转账和对冲转币各加一行进度（提币 → 链上 → 到账 → 进交易账户；同时开仓 → 转币 → 平仓 → 回款），对冲转币还写买入和对冲的数量差（敞口）。
- 交易台状态条加"今日 已用 / 每日上限"，改完额度马上能看到。
- 手机上交易计划面板的步骤不再压在"技术详情"下面。
- **自动补币到账正好是要的数**：原来一律当"手续费从提币数量里扣"算，但余额又按"数量 + 手续费"核，两头对不上：手续费从数量里扣的交易所到账少一笔手续费。现在按每家的口径算：OKX、Bybit、Kraken 的手续费另外收，就提要的数；KuCoin、Bitget、币安、Gate 从数量里扣，就提"要的数 + 手续费"。
- OKX 提币被要求填收款人信息（旅行规则），或身份认证不够时，按"没发出 + 需要你"处理并写清原因，不再算结果不明。
- Kraken 合约的订单按编号读回时，不再把挂在簿上的单、已经成交的单都读成"被拒"：交易所返回的状态词（在簿上、全部成交、已取消、触发单已挂等）现在都按文档映射，认不出的词会停下等人，不再当成被拒。
- 币安订单读回认得文档里的两个状态词：`PENDING_NEW` 当等待（还没进簿），`EXPIRED_IN_MATCH`（自成交保护把单子过期了）当终态并带上已成交数量，以前这两个词会让这一单停在“需要你”。
- **程序只读安装目录里的 .env**：原来会从启动目录一级级往上找 .env，测试时挂了生产目录就读到了生产的明文 Key。现在只读两处：环境变量 `CROSSLINE_ENV_FILE` 指定的文件，或者安装目录里的 .env。设置页保存的凭证也写进同一个文件。启动日志里写着读了哪个文件（只写路径）。
- KuCoin 现货规格刷新修复：KuCoin 有 16 个法币计价的交易对（如 BTC-EUR）的最小下单金额字段是空值，批 50 起这一个空值会让整张 KuCoin 现货规格表读不进来（日志里每分钟一条“instrument refresh failed”）；现在这些交易对照常读，最小金额回退到 quoteMinSize。
